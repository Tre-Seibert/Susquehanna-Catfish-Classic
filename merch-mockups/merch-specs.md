# Merchandise Specs — Susquehanna Catfish Classic

Printer-facing specifications. Pair with the artwork generated from `logos/IMAGE-GEN-PROMPTS.md` (prompts 6 and 7).

**Standing constraint: three inks maximum on any piece.** Every additional color is another screen and another setup fee. The faded three-color look is also more authentically vintage than a full-color print, so this is an aesthetic win, not just a cost cut.

---

## T-Shirt

**Garment:** Heather oatmeal, heather slate, or washed rust. Avoid pure white and pure black — they fight the warm palette. Comfort Colors 1717 or Next Level 6210 are good heritage-feel blanks.

### Front — left chest
| Spec | Value |
|---|---|
| Art | Circular badge mark |
| Width | 3.5 in |
| Placement | 2 in below shoulder seam, aligned with wearer's left chest |
| Inks | Susquehanna Slate `#2E4A52`, Rust Red `#A8442A`, Aged Oat `#EDE4D0` |

### Back — full width
| Spec | Value |
|---|---|
| Art | Catfish illustration + wordmark, banners above and below |
| Width | 11 in across shoulders |
| Placement | 3 in below collar |
| Copy | `SUSQUEHANNA` / catfish / `CATFISH CLASSIC` / `EST. 2027` |
| Inks | Same three |

**Print note:** request a soft-hand / waterbase or discharge print. Standard plastisol sits on top of the fabric and kills the vintage feel. Ask for light distressing in the separation so it reads worn from day one.

- [ ] Confirmed ≤ 3 inks per piece
- [ ] Print dimensions and placement measurements included
- [ ] One-color version supplied as fallback
- [ ] Garment blanks confirmed in stock in the full size run before the order goes in
